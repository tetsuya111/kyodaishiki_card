# spec `rag-reference-control` から固定カードを削除し、参照枚数の指定に絞り込み

- 日時: 2026-09-17 21:10
- 種別: docs（`.kiro/specs/`、Git 管理外）

## 何を行ったか

- `.kiro/specs/rag-reference-control/requirements.md` を全面的に修正した。
  - 旧ストーリー3（参照するカードの固定）と旧ストーリー4（固定カードを用いた対話）を削除した。固定カードに関するゴール、成功指標、非機能要件、依存関係、未解決事項、用語も削除した。
  - 「参照するカードそのものの指定・固定」を Non-Goals に明記した。
  - ストーリーを次の 4 つに再構成した。
    1. 対話で参照するカード枚数のコマンド指定
    2. 参照枚数の既定値を 15 枚にする
    3. `/rag last` の表示枚数の指定
    4. 自然言語からの操作とヘルプ
  - 「依頼文の解釈についての前提」と、それに対応する未解決事項を削除した。
  - 非機能要件に、既定値の引き上げによる入力トークン増（コスト）を追加した。
- `.kiro/specs/README.md` のスペック一覧の概要を「参照枚数のコマンド指定（既定 15 枚）と `/rag last` の表示枚数指定」に更新した。

## なぜ行ったか

- 利用者から、当初の依頼文の意図は「対話で参照する**カードの枚数**をコマンドから指定できるようにする」であり、カードそのものの指定ではなかったとの訂正があったため。
- あわせて、参照枚数の既定値は 15 枚とする指示があったため。

## 補足

- コードは変更していない。design.md / tasks.md は要件の合意後に作成する。
